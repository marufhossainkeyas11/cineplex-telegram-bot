# STAR Cineplex Telegram Bot v2 (Live Branch Showtimes + Zero-Miss Alerts)

Render Free Web Service-এ ফ্রিতে হোস্ট করার জন্য তৈরি সম্পূর্ণ Node.js (`grammY` + `Express` + `PostgreSQL`) টেলিগ্রাম বট। ব্যাকএন্ড API ও স্ক্র্যাপ সোর্স সম্পূর্ণ গোপন রেখে ইউজারদের কাছে শুধু **STAR Cineplex (`https://cineplexbd.com`)** দেখায়।

## নতুন কী যুক্ত হয়েছে (v2)
- **সব ৯টি ব্রাঞ্চের লাইভ শোটাইম, খালি সিট ও দাম**: প্রতিটি ব্রাঞ্চের RSC পেলোড থেকে লাইভ `shows[]` ও `halls[]` পার্স করে হলের নাম, ১২-ঘণ্টার সময় (`2:00 PM`), খালি সিটের সংখ্যা (`🟢 235/248 সিট`) এবং টাকায় টিকিটের দাম (`paisa ÷ 100 = ৳400–৳500`) দেখায়।
- **পছন্দের ব্রাঞ্চ টার্গেটিং**: ইউজার `/branches` থেকে নিজের ফেভারিট ব্রাঞ্চ সেট করতে পারবে এবং যেকোনো মুভির জন্য নির্দিষ্ট ব্রাঞ্চ (যেমন শুধু Bashundhara City) অথবা সব ব্রাঞ্চের অ্যালার্ট সেট করতে পারবে।
- **জিরো-মিস মাল্টি-সিগন্যাল অ্যালার্ট ইঞ্জিন**:
  1. ক্যাটালগে `isNowShowing` আপডেট হওয়ার আগেই কোনো ব্রাঞ্চে `status: "Selling"` ও খালি সিটযুক্ত শো এলেই সাথে সাথে অ্যালার্ট পাঠায় (ব্রাঞ্চ, হল, সময়, সিট ও দামসহ)।
  2. কনফার্মড টেলিগ্রাম ডেলিভারির পরেই `notified_show_ids` মার্ক করে—ফলে ক্র্যাশ বা নেটওয়ার্ক এরর হলেও পরের ক্রনে অ্যালার্ট মিস হয় না।
  3. **Continuous Mode (`🔁`)**: চাইলে একটি মুভির নতুন ডেট বা উইকেন্ড শোটাইম ছাড়লেও প্রতিবার অ্যালার্ট পাওয়া যাবে।
- **অটো ডাটাবেস মাইগ্রেশন**: আগের Neon PostgreSQL ডাটাবেস থাকলে কোনো ম্যানুয়াল SQL ছাড়াই নতুন কলামগুলো অটোমেটিক তৈরি হয়ে যাবে।

## Render-এ আপডেট করার ধাপ
1. GitHub রিপোতে নতুন ফাইলগুলো পুশ করে Render-এ **Manual Deploy → Deploy latest commit** দিন।
2. আগের `BOT_TOKEN`, `DATABASE_URL`, `WEBHOOK_SECRET`, `CRON_SECRET`, `PUBLIC_SITE_URL` (`https://cineplexbd.com`) ঠিক রাখুন।
3. **দ্রুততম টিকিট অ্যালার্টের জন্য** [cron-job.org](https://cron-job.org)-এ `/cron/check?secret=YOUR_CRON_SECRET` পিং ইন্টারভ্যাল **৫ মিনিট** (বা ১০ মিনিট) সেট করুন।
